# Publication.today

A multi-sector digital publication built with plain HTML, CSS, and JavaScript for GitHub Pages.

## Deploy

1. Open **Settings → Pages** in this repository.
2. Select **Deploy from a branch**.
3. Choose `main` and `/ (root)`, then save.
4. Add `publication.today` under the custom domain field when DNS is configured.

## Content

Edit `data/articles.json` to add or update articles. The site currently includes six editorial sections and a searchable article directory.

## Important

This is a static site. It has no server-side database, private admin dashboard, or backend API. Health-related content is educational and should be medically reviewed before publication.
